Professional reviewer-facing website for the VELOOP Rewards Product Analytics, Data Readiness & Data Management Blueprint.

## Run / deploy
This is a static, dependency-free HTML site. The Vercel project root directory is `submission-site`; no build command is required. Entry point: `index.html`.
