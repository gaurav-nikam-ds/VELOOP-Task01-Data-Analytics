# VELOOP Task 01 — Reproducible data evidence

**Data notice:** All assignment workbooks are simulated. None of these findings are VELOOP production performance.

## Workflows

### Supplied Task 01 user-profile workbook
- `python/analyze_task01.py`: profiles `Users_1000_Clean` and compares `Users_Messy_Audit`.
- `sql/task01_analysis.sql`: SQLite checks and descriptive queries.
- `evidence/`: aggregate-only quality summary and missingness visualization.

### Supplemental synthetic test pack
- `python/analyze_synthetic_pack.py`: profiles the QA-checked synthetic Task Activity, Rewards, Wallet, Withdrawals, Referrals, Feature Events and Messy Data tables.
- `sql/synthetic_test_pack_analysis.sql`: tests joins, status distributions, KPI feasibility examples, chronology and injected data-quality defects.
- `evidence/synthetic_*`: aggregate profile, status, quality, relationship and KPI-feasibility evidence.
- The test pack uses Task 01 user IDs as parent keys, but all added transaction/event rows are synthetic. The separate Task 02 behavior workbook is not imported or merged.
- The local SQLite database is created only for execution and is not committed.

## Run

Install dependencies:
`python -m pip install pandas openpyxl matplotlib`

Task 01 profile:
```bash
python analytics/python/analyze_task01.py --input "/path/to/VELoop_Rewards_Data_01.xlsx" --output-dir outputs
```

Supplemental synthetic pack:
```bash
python analytics/python/analyze_synthetic_pack.py --input "/path/to/SIMULATED_Analytics_Test_Data.xlsx" --users "/path/to/VELoop_Rewards_Data_01.xlsx" --output-dir outputs
```

Run each SQL file against the local SQLite database generated by its corresponding script. Use DBeaver, DB Browser for SQLite or SQLite CLI.

## Interpretation boundaries
- Missing values are not automatically defects; evaluate requiredness and lifecycle semantics.
- Keep reward units separate; do not aggregate XP, VE, Gems, Tokens or currency without an approved conversion.
- Pending/open workflow states affect KPI denominators and cohort maturity.
- The synthetic pack has one self-referral and 52 wallet reference IDs requiring review in the broad polymorphic reference check.
- No generated counts, status shares, reward amounts, withdrawal metrics, retention or conversion figures may be represented as actual company results.
- Production validation requires authorized source data and approved business definitions.
